# SpeedFast - Semana 3

Actividad sumativa de Desarrollo Orientado a Objetos II.

## Contenidos implementados
- Clase abstracta `Pedido`.
- Herencia: `PedidoComida`, `PedidoEncomienda` y `PedidoExpress`.
- Polimorfismo mediante sobrescritura de `asignarRepartidor()` y `calcularTiempoEntrega()`.
- Sobrecarga de `asignarRepartidor(String nombre)`.
- Interfaces `Despachable`, `Cancelable` y `Rastreable`.
- Simulación en `Main` de asignación automática/manual, tiempo estimado, despacho, cancelación e historial.

## Ejecución
Ejecutar la clase `Main` desde IntelliJ IDEA.
