# SpeedFast - Desarrollo Orientado a Objetos II

Actividad formativa Semana 1: **Explorando la sobrecarga y sobreescritura en clases derivadas**.

## Descripción
Proyecto Java que representa tres tipos de pedidos de la empresa SpeedFast: comida, encomienda y compra express. Se aplican herencia, encapsulamiento, sobrescritura, sobrecarga y polimorfismo.

## Clases
- `Pedido`: clase base con atributos encapsulados y métodos `asignarRepartidor()`.
- `PedidoComida`: valida mochila térmica.
- `PedidoEncomienda`: valida peso y embalaje.
- `PedidoExpress`: busca disponibilidad inmediata y cercanía.
- `Main`: instancia y prueba los distintos tipos de pedidos mediante referencias de tipo `Pedido`.
